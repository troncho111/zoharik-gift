## משימות לקלוד קוד

### משימה 1️⃣ - יצירת תמונת התצוגה המקדימה

הרץ את הפקודות הבאות:

```bash
npm install puppeteer
node screenshot.js
```

זה ייצור קובץ `preview.png` בגודל 2400x1260 (איכות retina).

**אם האימוג'י 🎁 לא מופיע בתמונה (יוצא כריבוע):**

על Linux/Ubuntu:
```bash
sudo apt-get install fonts-noto-color-emoji
node screenshot.js
```

על Mac/Windows: בדרך כלל עובד מהקופסה.

### משימה 2️⃣ - העלאה לשרת ועדכון gift.html

לאחר שיש לך את `preview.png`:

1. **תעלה את preview.png לשרת** (לתיקייה שיהודה ייעד, לדוגמא `public_html/gift/`)

2. **תקבל את הכתובת המלאה**, למשל:
   `https://yourdomain.com/gift/preview.png`

3. **עדכן את gift.html:** חפש את השורות עם `og:image` ו-`twitter:image` (יש שתי שורות), והחלף את ה-URL מ:
   ```
   https://images.unsplash.com/photo-1513885535751-8b9238bd345a?w=1200&h=630&fit=crop&q=85
   ```
   לכתובת החדשה של preview.png אצל יהודה.

4. **תעלה את gift.html לשרת** לאותה תיקייה.

5. **תן ליהודה את הכתובת הסופית** של gift.html.

### משימה 3️⃣ - בדיקת התצוגה המקדימה

יהודה ישלח את הלינק בוואטסאפ. צריך לוודא שמופיע:
- תמונה (preview.png)
- כותרת: "🎁 זוהריקו ואורטלי - יש לכם מתנה!"
- תיאור: "מאת יהודה מזרחי, האיש והאגדה. לחצו כדי לפתוח את ההפתעה 😇"

**אם וואטסאפ מציג תצוגה מקדימה ישנה:** וואטסאפ שומר תמונות במטמון. הוסף `?v=2` בסוף הכתובת (`https://yourdomain.com/gift/?v=2`) כדי לכפות רענון.

## הערות טכניות

- **og:image חייב להיות כתובת מלאה (https://...), לא יחסית** - וואטסאפ לא תומך בכתובות יחסיות.
- כל הקבצים יכולים להיות באותה תיקייה בשרת.
- העמוד עובד בעברית RTL, מותאם למובייל וכולל קונפטי, אנימציות, ותגיות OG מלאות.
- וואטסאפ של זוהר/אורטלי ייפתח עם הודעה מוכנה: "היי יהודה 🎁 בחרנו ב-[האפשרות] (1,000 ₪). תודה רבה!"
